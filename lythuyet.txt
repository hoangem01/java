* Các package có sẵn của thư viện chuẩn Java

1. import java.util.*; Xử lý dữ liệu bao gồm:

+ Nhập xuất cơ bản: Scanner

+ Cấu trúc dữ liệu (Collections): ArrayList, List, LinkedList, Map, HashMap, Set.

+ Các lớp tiện ích: Arrays, Collections, Comparator, Objects, UUID, Random.

2. import java.io.*; Xử lý File bao gồm:

+ Đọc/Ghi cơ bản: File, FileReader, FileWriter.

+ Đọc/Ghi hiệu suất cao: BufferedReader, BufferedWriter.

+ Bắt lỗi: IOException, FileNotFoundException.

3. import java.time.*; và import java.time.format.*; Xử lý Thời gian bao gồm:

+ (java.time.*) lấy các class cốt lõi: LocalDate, LocalTime, LocalDateTime, Period.
 
+ (java.time.format.*) lấy công cụ định dạng: DateTimeFormatter (để in ngày tháng 
theo kiểu "dd/MM/yyyy").

* Các lệnh in dữ liệu ra màn hình:

- System.out.print("text");: In chuỗi ra màn hình và giữ con trỏ chuột ở lại 
trên cùng dòng đó.

- System.out.println("text");: In chuỗi ra màn hình và tự động xuống dòng 
(tương đương với việc thêm ký tự \n ở cuối).

- System.out.printf("format", args);: In chuỗi theo định dạng

+ Các ký tự "giữ chỗ" (Format Specifiers) cơ bản:
Ký tự        Kiểu dữ liệu tương ứng                     Ví dụ

%d        Số nguyên (byte, short, int, long)           10, -25
%f        Số thực (float, double)                   3.14159, -0.5
%s          Chuỗi văn bản (String)                     "Java"
%c          Một ký tự (char)                            'A'
%b          Đúng/Sai (boolean)                      true, false
%n (\n)      Ký tự xuống dòng

Ví dụ:
String name = "Hoang";
int age = 25;
// Nối chuỗi bằng println 
System.out.println("Tên tôi là " + name + ", năm nay tôi " + age + " tuổi."); 

// Dùng printf 
System.out.printf("Tên tôi là %s, năm nay tôi %d tuổi.", name, age);

- Định dạng độ chính xác cho số thực (float/double):
Sử dụng lệnh System.out.printf kết hợp với cú pháp %.nf (trong đó n là số lượng 
chữ số thập phân bạn muốn giữ lại). Java sẽ tự động làm tròn số.

Ví dụ:
double pi = 3.14159265;
System.out.printf("Pi với 2 số thập phân: %.2f\n", pi); // In ra: 3.14
System.out.printf("Pi với 4 số thập phân: %.4f\n", pi); // In ra: 3.1416

* Nhập dữ liệu (Input)
Cách đơn giản và phổ biến nhất trong Java là sử dụng class Scanner thuộc thư viện 
java.util.
Ví dụ:
    Scanner sc = new Scanner(System.in);

    System.out.print("Nhập một số nguyên: ");
    int a = sc.nextInt();                   // Đọc số nguyên (int)

    System.out.print("Nhập một số thực: ");
    double b = sc.nextDouble();             // Đọc số thực (double)

    // LƯU Ý QUAN TRỌNG: Xóa bộ nhớ đệm
    sc.nextLine(); 
    System.out.print("Nhập họ và tên: ");
    String name = sc.nextLine();            // Đọc toàn bộ một dòng chữ 
                                            (bao gồm cả dấu cách)
    sc.close();                             // Đóng Scanner khi không dùng nữa để
                                            giải phóng bộ nhớ
  
-> Lỗi "trôi lệnh" thường gặp: Khi bạn dùng các hàm đọc số như nextInt(), nextDouble(), 
chúng chỉ lấy con số mà để lại ký tự Enter \n trong bộ đệm. Nếu gọi ngay nextLine() 
sau đó, nó sẽ đọc trúng ký tự Enter này và kết thúc ngay lập tức. 
Cần gọi một lệnh sc.nextLine() trống ở giữa để "ăn" ký tự Enter thừa đó.

* Các hàm trong thư viện Math
- Thư viện java.lang.Math được tích hợp sẵn (không cần import) và chứa các phương thức 
tĩnh (static) dùng để tính toán toán học. Bạn gọi hàm trực tiếp thông qua tên lớp Math.
             
+ Math.abs(x): Trị tuyệt đối             
+ Math.pow(a, b): Lũy thừa ($a^b$)          
+ Math.sqrt(x): Căn bậc 2                 
+ Math.max(a, b): Trả về số lớn nhất        
+ Math.min(a, b): Trả về số nhỏ nhất        
+ Math.round(x ): Làm tròn đến số nguyên gần nhất           //Math.round(3.6)  ->  4
+ Math.ceil(x): Làm tròn lên                                //Math.ceil(3.1)   ->  4.0
+ Math.floor(x):  Làm tròn xuống                            //Math.floor(3.9)  ->  3.0

-> Hằng số hữu ích: Math.PI trả về giá trị số Pi ~ 3.14159265. Tất cả các hàm như pow
hay sqrt đều trả về kiểu double

* Kiểu dữ liệu (Data type):
💡 Ngôn ngữ lập trình Java cung cấp các kiểu dữ liệu để biểu diễn dữ liệu kiểu số nguyên,   
số thực, ký tự, đúng sai, xâu ký tự...

Kiểu dữ liệu	    Kích thước (byte)	        Giá trị
byte	            1 byte	                -128 đến 127
short	            2 byte	                -32768 đến 32767
int	             4 byte = 32bit	            -2^31 đến 2^31 - 1
long	         8 byte = 64bit	            -2^63 đến 2^63 - 1
float	            4 byte	                Số thực độ chính xác từ 6 - 7 chữ số sau dấu phẩy
double	            8 byte	                Số thực độ chính xác tới 15 chữ số sau dấu phẩy
char	            2 byte	                Lưu các ký tự
boolean	            1 byte	                Lưu giá trị true (đúng) hoặc false (sai)


Ví dụ về khai báo biến:
public class Main {
    public static void main(String[] args) {
        int banKinh = 100;
        long dienTich = 10182383812838123L;
        float PI = 3.14F;
        double temp = 30.89129391293D;
        boolean kiemTra = true;
        char kiTu = '@';
    }
}


Hiển thị giá trị của biến số thực với độ chính xác cho trước:
public class Main {
    public static void main(String[] args) {
        float chuVi = 3.18238f;
        double dienTich = 39.91293912391293d;
        System.out.printf("%.2f\n", chuVi);
        System.out.printf("%.10f\n", dienTich);
    }
}

* Mảng 1 chiều (Array)

- Kích thước cố định: Một khi đã khởi tạo, không thể thay đổi số lượng phần tử của mảng.
- Kiểu dữ liệu đồng nhất: Tất cả phần tử trong mảng phải có cùng một kiểu dữ liệu.
- Lưu trữ liên tiếp: Cấp phát bộ nhớ thành một dải liên tục, truy xuất cực nhanh qua chỉ số 
(index) bắt đầu từ 0 đến length - 1

- Cách khai báo và khởi tạo:
Cách 1: Khai báo mảng rỗng với số lượng phần tử cố định (ví dụ 5)
int[] arr1 = new int[5]; // Các phần tử mặc định là 0
Cách 2: Khai báo và gán sẵn giá trị
int[] arr2 = {10, 20, 30, 40, 50}; 

- Duyệt mảng (Nhập/Xuất):
Scanner sc = new Scanner(System.in);
System.out.print("Nhập số phần tử: ");
int n = sc.nextInt();
int[] a = new int[n];

// Nhập dữ liệu bằng vòng lặp for truyền thống
for (int i = 0; i < n; i++) {
    a[i] = sc.nextInt();
}

// Xuất dữ liệu bằng for-each (ngắn gọn, dùng khi chỉ cần đọc giá trị)
for (int item : a) {
    System.out.print(item + " ");
}

* Arrays.sort và Comparator

- Arrays.sort là một hàm tĩnh (static) trong thư viện java.util.
Arrays dùng để sắp xếp các phần tử trong mảng. Mặc định, hàm này sẽ sắp xếp theo chiều 
tăng dần.

- Sử dụng Comparator (Tùy chỉnh luật sắp xếp):
Comparator là một interface cho phép bạn tự định nghĩa lại cách so sánh hai phần tử 
(ví dụ: muốn sắp xếp giảm dần, hoặc sắp xếp theo độ dài chuỗi).

+ Lưu ý cực kỳ quan trọng: Bạn không thể dùng Comparator cho mảng kiểu nguyên thủy 
(như int[], double[]). Bạn bắt buộc phải dùng mảng kiểu đối tượng 
(như Integer[], Double[], String[]).

public class Main {
    public static void main(String[] args) {
        int[] arrAsc = {5, 2, 8, 1};
        Arrays.sort(arrAsc);            // Kết quả: 1, 2, 5, 8

        Integer[] arrDesc = {5, 2, 8, 1};
        
        // Tự viết luật bằng biểu thức Lambda (Cú pháp mũi tên)
        Arrays.sort(arrDesc, (a, b) -> b - a); 
    }
}

+ int: Không thể dùng trong ArrayList<int>, không có hàm nào.
+ Integer: Bắt buộc dùng cho ArrayList<Integer>, Có nhiều hàm hỗ trợ.

* ArrayList: hoạt động như một mảng động có kích thước tự động tăng hoặc giảm khi bạn thêm 
hoặc xóa phần tử.

- Khởi tạo danh sách mẫu:
ArrayList<Integer> list = new ArrayList<>();

+ hàm Thêm phần tử
add(giá_trị): Thêm một phần tử vào cuối danh sách.

list.add(10); 
list.add(20);                   // list hiện tại: [10, 20]
list.add(1, 15);                // Chèn số 15 vào index 1. 
                                Kết quả: [10, 15, 20]

-> add(vị_trí, giá_trị): Chèn một phần tử vào một vị trí (index) cụ thể. 
Các phần tử phía sau sẽ tự động lùi lại một bước.

+ hàm Truy xuất và Tìm kiếm
• get(index): Lấy giá trị của phần tử tại vị trí index (tương đương 
arr[index] của mảng thường).
int x = list.get(0);                    // Trả về 10

• size(): Lấy tổng số lượng phần tử đang có trong danh sách 
(tương đương arr.length).
int count = list.size();                // Trả về 3

• contains(giá_trị): Kiểm tra xem một giá trị có tồn tại trong danh sách hay không. 
Trả về true hoặc false.
boolean check = list.contains(15);      // Trả về true

• indexOf(giá_trị): Tìm và trả về index đầu tiên của giá trị đó. Nếu không tìm thấy, 
trả về -1.
int pos = list.indexOf(20);             // Trả về 2

• isEmpty(): Kiểm tra xem danh sách có rỗng hay không. Trả về true nếu danh sách 
không có phần tử nào (size = 0).

+ hàm Cập nhật và Xóa
• set(index, giá_trị_mới): Ghi đè/thay đổi giá trị của phần tử tại vị trí index 
(tương đương arr[index] = giá_trị_mới).
list.set(0, 99);                        // list trở thành: [99, 15, 20]

• remove(index): Xóa phần tử tại vị trí index. Các phần tử phía sau sẽ tự động dồn lên trước.
list.remove(1);                         // Xóa phần tử ở index 1 (số 15). Kết quả: [99, 20]

• remove(Object): Xóa phần tử theo giá trị (chỉ xóa phần tử đầu tiên tìm thấy). 
Lưu ý: Với ArrayList kiểu số nguyên, bạn phải ép kiểu để tránh nhầm với hàm remove(index).
list.remove(Integer.valueOf(99));       // Xóa số 99. Kết quả: [20]

• clear(): Xóa sạch toàn bộ dữ liệu, biến ArrayList về trạng thái rỗng.

+ hàm Sắp xếp (Sort)
• Khác với mảng tĩnh dùng Arrays.sort(), với ArrayList bạn có 2 cách để sắp xếp:

- Dùng list.sort() (Tăng dần):
list.sort(list); 

- Dùng Lambda Expression: 
Cú pháp:
(danh_sách_tham_số) -> thân_biểu_thức

+ Được phép dùng Lambda: Integer[], String[], Double[], hoặc mảng chứa các 
object do bạn tự định nghĩa.

+ Báo lỗi biên dịch: int[], double[], char[], long[]

Ví dụ:
public class Main {
    public static int tinhTongChuSo(int n) {
        int sum = 0;
        n = Math.abs(n);
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        return sum;
    }

    public static void main(String[] args) {

        List<Integer> arr = new ArrayList<>(Arrays.asList(12, 23, 104, 51, 9));

        arr.sort((o1, o2) -> {
            int tong1 = tinhTongChuSo(o1);
            int tong2 = tinhTongChuSo(o2);
            
            if (tong1 != tong2) {
                return tong1 - tong2; 
            }
            return o2 - o1; 
        });

        System.out.println(arr);
    }
}
+ Hàm toArray(): Trả về mảng chứa các object tương tự như trong array list.

public static void main(String[] args) {
    List<Integer> arr = new ArrayList<>();
    int a[] = {1, 2, 2, 2, 3, 3, 5};
    for(int x: a)
        arr.add(x);
    Object[] b = arr.toArray();
    for(Object x: b)
        System.out.print(x + " ");
}

+ Hàm forEach(): Cung cấp một áp dụng hàm nào đó với lần lượt các phần tử 
trong array list.   

public static void main(String[] args) {
    int a[] = {1, 2, 2, 2, 3, 3, 5};
    List<Integer> arr = new ArrayList<>();
    for(int x : a){
        arr.add(x);
    }
    arr.forEach((n) -> System.out.print(n + " "));
}
