* Các package có sẵn của thư viện chuẩn Java

1. import java.util.*; Xử lý dữ liệu bao gồm:

+ Nhập xuất cơ bản: Scanner

+ Cấu trúc dữ liệu (Collections): ArrayList, List, LinkedList, Map, HashMap, Set.

+ Đọc/Ghi hiệu suất cao: BufferedReader, BufferedWriter.

* Các lệnh in dữ liệu ra màn hình:

- System.out.print("text");: In chuỗi ra màn hình và giữ con trỏ chuột ở lại 
trên cùng dòng đó.

- System.out.println("text");: In chuỗi ra màn hình và tự động xuống dòng 
(tương đương với việc thêm ký tự \n ở cuối).

- System.out.printf("format", args);: In chuỗi theo định dạng

+ Các ký tự "giữ chỗ" (Format Specifiers) cơ bản:
Ký tự        Kiểu dữ liệu tương ứng                     Ví dụ

%d        Số nguyên (byte, short, int, long)           10, -25
%f        Số thực (float, double)                   3.14159, -0.5
%s          Chuỗi văn bản (String)                     "Java"
%c          Một ký tự (char)                            'A'
%b          Đúng/Sai (boolean)                      true, false
%n (\n)      Ký tự xuống dòng

Ví dụ:
String name = "Hoang";
int age = 25;
// Nối chuỗi bằng println 
System.out.println("Tên tôi là " + name + ", năm nay tôi " + age + " tuổi."); 

// Dùng printf 
System.out.printf("Tên tôi là %s, năm nay tôi %d tuổi.", name, age);

- Định dạng độ chính xác cho số thực (float/double):
Sử dụng lệnh System.out.printf kết hợp với cú pháp %.nf (trong đó n là số lượng 
chữ số thập phân bạn muốn giữ lại). Java sẽ tự động làm tròn số.

Ví dụ:
double pi = 3.14159265;
System.out.printf("Pi với 2 số thập phân: %.2f\n", pi); // In ra: 3.14
System.out.printf("Pi với 4 số thập phân: %.4f\n", pi); // In ra: 3.1416

* Nhập dữ liệu (Input)
Cách đơn giản và phổ biến nhất trong Java là sử dụng class Scanner thuộc thư viện 
java.util.
Ví dụ:
    Scanner sc = new Scanner(System.in);

    System.out.print("Nhập một số nguyên: ");
    int a = sc.nextInt();                   // Đọc số nguyên (int)

    System.out.print("Nhập một số thực: ");
    double b = sc.nextDouble();             // Đọc số thực (double)

    // LƯU Ý QUAN TRỌNG: Xóa bộ nhớ đệm
    sc.nextLine(); 
    System.out.print("Nhập họ và tên: ");
    String name = sc.nextLine();            // Đọc toàn bộ một dòng chữ 
                                            (bao gồm cả dấu cách)
    sc.close();                             // Đóng Scanner khi không dùng nữa để
                                            giải phóng bộ nhớ
  
-> Lỗi "trôi lệnh" thường gặp: Khi bạn dùng các hàm đọc số như nextInt(), nextDouble(), 
chúng chỉ lấy con số mà để lại ký tự Enter \n trong bộ đệm. Nếu gọi ngay nextLine() 
sau đó, nó sẽ đọc trúng ký tự Enter này và kết thúc ngay lập tức. 
Cần gọi một lệnh sc.nextLine() trống ở giữa để "ăn" ký tự Enter thừa đó.

* Arrays.sort và Comparator

- Arrays.sort là một hàm tĩnh (static) trong thư viện java.util.
Arrays dùng để sắp xếp các phần tử trong mảng. Mặc định, hàm này sẽ sắp xếp theo chiều 
tăng dần.

- Sử dụng Comparator (Tùy chỉnh luật sắp xếp):
Comparator là một interface cho phép bạn tự định nghĩa lại cách so sánh hai phần tử 
(ví dụ: muốn sắp xếp giảm dần, hoặc sắp xếp theo độ dài chuỗi).

+ Lưu ý cực kỳ quan trọng: Bạn không thể dùng Comparator cho mảng kiểu nguyên thủy 
(như int[], double[]). Bạn bắt buộc phải dùng mảng kiểu đối tượng 
(như Integer[], Double[], String[]).

public class Main {
    public static void main(String[] args) {
        int[] arrAsc = {5, 2, 8, 1};
        Arrays.sort(arrAsc);            // Kết quả: 1, 2, 5, 8

        Integer[] arrDesc = {5, 2, 8, 1};
        
        // Tự viết luật bằng biểu thức Lambda (Cú pháp mũi tên)
        Arrays.sort(arrDesc, (a, b) -> b - a); 
    }
}

* ArrayList: hoạt động như một mảng động có kích thước tự động tăng hoặc giảm khi bạn thêm 
hoặc xóa phần tử. Cho phép chứa giá trị null

- Duyệt ArrayList:
public class Main {
    public static void main(String[] args) {
        // 1. KHAI BÁO
        
        ArrayList<Integer> numbers = new ArrayList<>();

        // 2. NHẬP DỮ LIỆU (INPUT)

        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        for (int i = 0; i < n; i++) {
            System.out.print("Nhập phần tử thứ " + (i + 1) + ": ");
            int value = scanner.nextInt();
            numbers.add(value); 
        }

        // 3. XUẤT DỮ LIỆU (OUTPUT)
        
        // Cách 1: In trực tiếp 
        System.out.println(numbers);

        // Cách 2: Dùng vòng lặp for truyền thống 
        for (int i = 0; i < numbers.size(); i++) { 
            System.out.print(numbers.get(i) + " "); // Dùng hàm get(i) để lấy giá trị tại vị trí i
        }

        // Cách 3: Dùng vòng lặp for-each 
        for (Integer num : numbers) {
            System.out.print(num + " ");
        }
    }
}

+ hàm Thêm phần tử
add(giá_trị): Thêm một phần tử vào cuối danh sách.

list.add(10); 
list.add(20);                   // list hiện tại: [10, 20]
list.add(1, 15);                // Chèn số 15 vào index 1. 
                                Kết quả: [10, 15, 20]

-> add(vị_trí, giá_trị): Chèn một phần tử vào một vị trí (index) cụ thể. 
Các phần tử phía sau sẽ tự động lùi lại một bước.

+ hàm Truy xuất và Tìm kiếm

• get(index): Lấy giá trị của phần tử tại vị trí index (tương đương 
arr[index] của mảng thường).
int x = list.get(0);                    // Trả về 10

• size(): Lấy tổng số lượng phần tử đang có trong danh sách 
(tương đương arr.length).
int count = list.size();                // Trả về 3

• contains(giá_trị): Kiểm tra xem một giá trị có tồn tại trong danh sách hay không. 
Trả về true hoặc false.
boolean check = list.contains(15);      // Trả về true

• indexOf(giá_trị): Tìm và trả về index đầu tiên của giá trị đó. Nếu không tìm thấy, 
trả về -1.
int pos = list.indexOf(20);             // Trả về 2

• isEmpty(): Kiểm tra xem danh sách có rỗng hay không. Trả về true nếu danh sách 
không có phần tử nào (size = 0).

+ hàm Cập nhật và Xóa
• set(index, giá_trị_mới): Ghi đè/thay đổi giá trị của phần tử tại vị trí index 
(tương đương arr[index] = giá_trị_mới).
list.set(0, 99);                        // list trở thành: [99, 15, 20]

• remove(index): Xóa phần tử tại vị trí index. Các phần tử phía sau sẽ tự động dồn lên trước.
list.remove(1);                         // Xóa phần tử ở index 1 (số 15). Kết quả: [99, 20]

• remove(Object): Xóa phần tử theo giá trị (chỉ xóa phần tử đầu tiên tìm thấy). 
Lưu ý: Với ArrayList kiểu số nguyên, bạn phải ép kiểu để tránh nhầm với hàm remove(index).
list.remove(Integer.valueOf(99));       // Xóa số 99. Kết quả: [20]

• clear(): Xóa sạch toàn bộ dữ liệu, biến ArrayList về trạng thái rỗng.

+ hàm Sắp xếp (Sort)
• Khác với mảng tĩnh dùng Arrays.sort(), với ArrayList bạn có 2 cách để sắp xếp:

- Dùng list.sort() (Tăng dần):
list.sort(list); 

- Dùng Lambda Expression: 
Cú pháp:
(danh_sách_tham_số) -> thân_biểu_thức

+ Được phép dùng Lambda: Integer[], String[], Double[], hoặc mảng chứa các 
object do bạn tự định nghĩa.

+ Báo lỗi biên dịch: int[], double[], char[], long[]

Ví dụ:
public class Main {
    public static int tinhTongChuSo(int n) {
        int sum = 0;
        n = Math.abs(n);
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        return sum;
    }

    public static void main(String[] args) {

        List<Integer> arr = new ArrayList<>(Arrays.asList(12, 23, 104, 51, 9));

        arr.sort((o1, o2) -> {
            int tong1 = tinhTongChuSo(o1);
            int tong2 = tinhTongChuSo(o2);
            
            if (tong1 != tong2) {
                return tong1 - tong2; 
            }
            return o2 - o1; 
        });

        System.out.println(arr);
    }
}

* Set: là một interface đại diện cho khái niệm tập hợp toán học

Áp dụng set:
1. Các bài toán liên quan tới việc xóa, thêm, tìm kiếm một phần tử nào đó được thực hiện đi 
thực hiện lại nhiều lần.
2. Các bài toán liên quan tới các giá trị khác nhau của mảng.

Tính chất:
+ Không chứa phần tử trùng lặp: Nếu bạn sử dụng hàm add() để thêm một giá trị đã tồn tại 
trong Set, hệ thống sẽ tự động bỏ qua và trả về false.
+ Không truy cập dc chỉ số (Index)

- Cú pháp: Vì là một interface, bạn không thể khởi tạo trực tiếp Set bằng từ khóa new Set(). 
Bạn phải gọi thông qua các lớp triển khai của nó:

    Set<KiểuDữLiệu> tenSet = new TênLớpTriểnKhai<>();

* HashSet:
- Tính chất:
• HashSet chỉ lưu được các phần tử khác nhau.
• HashSet được cài đặt bằng bảng băm, vì thế tốc độ tìm kiếm 
phần tử đạt được là O(1).
• HashSet không có thứ tự, tức là các phần tử trong HashSet 
có thể xuất hiện nhiều thứ tự ngẫu nhiên.
• HashSet chỉ lưu được các phần tử kiểu đối tượng.
• Cho phép chứa duy nhất một phần tử null.

- Khai báo HashSet:
    Set<dataType> set1 = new HashSet<>();
    HashSet<dataType> set2 = new HashSet<>();

- Một số hàm thông dụng trong HashSet:
+ add(giá_trị) Thêm phần tử vào set
+ remove(giá_trị) Xóa phần tử khỏi set
+ size() Trả về số lượng phần tử trong set
+ contains(giá_trị) Kiểm tra sự tồn tại của 1 phần tử trong set
+ clear() Xóa mọi phần tử trong set
+ isEmpty() Trả về true nếu set rỗng, ngược lại trả về false

- Tìm số lượng giá trị khác nhau trong mảng số nguyên:

public static void main(String[] args) {
    Set<Integer> set1 = new HashSet<>();
    int[] a = {1, 1, 2, 1, 3, 1, 4, 4, 2};
    for(int x : a){
        set1.add(x);
    }
    System.out.println(set1.size());
}

- Duyệt set:

public static void main(String[] args) {
    Set<Integer> set1 = new HashSet<>();
    int[] a = {1, 1, 2, 1, 3, 1, 4, 4, 2};
    for(int x : a){
        set1.add(x);
    }
    for(int x : set1){
        System.out.print(x + " ");
    }
}

- Kiểm tra sự tồn tại của 1 giá trị trong set:

public static void main(String[] args) {
    Set<Integer> set1 = new HashSet<>();
    int[] a = {1, 1, 2, 1, 3, 1, 4, 4, 2};
    for(int x : a){
        set1.add(x);
    }
    if(set1.contains(1)){
        System.out.println("FOUND");
    }
    else{
        System.out.println("NOT FOUND");
    }
}

* LinkedHashSet

- Tính chất:
• LinkedHashSet chỉ lưu được các phần tử khác nhau.

• LinkedHashSet có thứ tự là thứ tự bạn thêm các phần tử vào set.
• LinkedHashSet chỉ lưu được các phần tử kiểu đối tượng.

- Khai báo LinkedHashSet:
    Set<dataType> set1 = new LinkedHashSet<>();

- Các hàm và ví dụ của LinkedHashSet tương tự như HashSet, trừ việc

+ Chuẩn hóa tên:
public class Main {
    public static void main(String[] args) {
        String s = "NgUYEN ThUY liNh";
        StringBuilder sb = new StringBuilder("");
        String[] arr = s.split("\\s+");
        for(String x : arr){
            sb.append(Character.toUpperCase(x.charAt(0)));
            for(int j = 1; j < x.length(); j++){
                sb.append(Character.toLowerCase(x.charAt(j)));
            }
            sb.append(" ");
        }
        sb.deleteCharAt(sb.length() - 1);       // xóa dấu cách thừa
        System.out.println(sb.toString());
    }
}

sb.insert(0, "Start: ");

+ delete(start, end): Xóa các ký tự từ vị trí start đến end - 1.
sb.delete(2, 5);

+ reverse(): Đảo ngược toàn bộ chuỗi ký tự.

- Ví dụ: Bạn cần xây dựng một lớp là Person để mô phỏng con người thì khi đó một đối tượng

3. Ép kiểu đối tượng và toán tử instanceof:
- Một biến tham chiếu của đối tượng có thể được ép sang tham chiếu của
một đối tượng thuộc lớp khác, đây được gọi là ép kiểu đối tượng

- Implicit casting và Explicit casting:
public class Main {
    public static void main(String[] args) {
        Object ob = new Student();                  //Implicit casting
        Student s = (Student)ob;                    // Explicit casting
    }
}

- Ta có thể ép một instance của lớp con sang một biến đối tượng của lớp cha (upcasting),
vì một đối tượng của lớp con bao giờ cũng là một đối tượng của lớp cha.
+ Instance ("đối tượng cụ thể") chính là một đối tượng thực tế được tạo ra từ một Class 
(lớp)

- Khi ép kiểu một instance của lớp cha sang biến đối tượng của lớp con (downcasting) bạn
phải tự đảm bảo rằng instance của lớp cha là một instance của lớp con, nếu không sẽ phát
sinh lỗi ClassCastException. Downcasting được thực hiện bằng Explicit casting

Ví dụ lỗi ClassCastException:
public class Main {
    public static void main(String[] args) {
        Person p1 = new Student();                  // upcasting
        Student s1 = (Student)p1;                   // Downcasting
        Person p2 = new Student();
        Staff s2 = (Staff)p2;                       // ClassCastException               
    }
}

- Sử dụng toán tử instanceof để tránh phát sinh lỗi:
+ Toán tử instanceof trong Java được sử dụng để kiểm tra xem một đối tượng (object) 
cụ thể có thực sự là một thể hiện (instance) của một Class, Subclass (lớp con) hay 
Interface nào đó hay không. Kết quả trả về của toán tử này luôn là một giá trị 
boolean (true hoặc false).

public class Main {
    public static void main(String[] args) {
        Person p1 = new Student();                  // upcasting
            if(p1 instanceof Student){
            System.out.println("OK1");
            Student s1 = (Student)p1;               // Downcasting
        }
        else{
            System.out.println("Error");
        }
        Person p2 = new Student();
        if(p2 instanceof Staff){
            System.out.println("OK2");
            Staff s2 = (Staff)p2;                  // ClassCastException
        }
        else{
            System.out.println("Error");
        }
    }
}

4. LỚP TRỪU TƯỢNG - ABSTRACT CLASS

Khái niệm và đặc điểm:

* Abstract class không thể sử dụng để tạo ra một đối tượng như các lớp thông thường, 
lớp trừu tượng có thể chứa các phương thức trừu tượng (abstract method) và sẽ được 
cài đặt chi tiết hơn ở các lớp con.

* Khi một lớp con kế thừa từ 1 lớp trừu tượng, tất cả các phương thức trừu tượng ở 
lớp cha phải được cài đặt cụ thể ở lớp con.

* Ví dụ: Lớp GeometricObject là lớp trừu tượng, có 2 lớp kế thừa từ nó là Circle và Rectangle. 
Trong trường hợp này 2 phương thức getArea() và getPerimeter() không thể cài đặt ở lớp cha 
vì nó còn phụ thuộc vào loại hình (tam giác, vuông, tròn...) vì thế 2 phương thức này 
được khai báo là trừu tượng.

* Trong thiết kế lớp với UML, lớp trừu tượng và phương thức trừu tượng được in nghiêng.

Lưu ý về lớp trừu tượng:

* Không thể tạo đối tượng từ lớp trừu tượng thông qua toán tử new, tuy nhiên bạn vẫn có thể 
tạo constructor cho lớp trừu tượng.

* Một lớp trừu tượng có thể không chứa phương thức trừu tượng.

* Lớp cha của một lớp trừu tượng có thể không phải là một lớp trừu tượng

* Một phương thức trừu tượng chỉ có thể được chứa trong một lớp trừu tượng 

* Nếu một lớp con không cài đặt mọi phương thức trừu tượng ở lớp cha(lớp trừu tượng) thì nó phải được khai báo 
là một lớp trừu tượng.

* Các phương thức trừu tượng không thể khai báo với từ khóa static.

* Bạn không thể tạo đối tượng từ lớp trừu tượng nhưng có thể sử dụng nó như một kiểu dữ liệu.
Ví dụ: GeometricObject ob1 = new Circle("Red", true, 10);

Code minh họa:

- Lớp GeometricObject:

public abstract class GeometricObject {
    private String color;
    private boolean filled;
    private java.util.Date dateCreated;
    protected GeometricObject() {}
    protected GeometricObject(String color, boolean filled) {
        this.color = color;
        this.filled = filled;
        this.dateCreated = new Date(System.currentTimeMillis());
    }
    public abstract double getArea();
    public abstract double getPerimeter();
}

- Lớp Circle:

public class Circle extends GeometricObject {
    private double radius;

    public Circle(String color, boolean filled, double radius) {
        super(color, filled);
        this.radius = radius;
    }
    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }
    @Override
    public double getPerimeter() {
        return 2 * Math.PI * radius;
    }

}

- Lớp Rectangle:

public class Rectangle extends GeometricObject {
    private double width, height;

    public Rectangle(double width, double height, String color, boolean filled) {
        super(color, filled);
        this.width = width;
        this.height = height;
    }
    @Override
    public double getArea() {
        return this.width * this.height;
    }
    @Override
    public double getPerimeter() {
        return 2 * (this.width + this.height);
    }
}

- Lớp Main và kết quả:

public class Main {
    public static boolean equalArea(GeometricObject o1, GeometricObject o2) {
        return o1.getArea() == o2.getArea();
    }

    public static void display(GeometricObject o) {
        System.out.println(o.getArea() + " " + o.getPerimeter());
    }

    public static void main(String[] args) {
        GeometricObject ob1 = new Circle("Red", true, 10);
        GeometricObject ob2 = new Rectangle(10, 20, "Green", true);

        System.out.println(equalArea(ob1, ob2));
        display(ob1);
        display(ob2);
    }
}

5. INTERFACE

Khái niệm và đặc điểm:

* Interface trong Java có cấu trúc tương tự như một lớp nhưng chỉ chứa các hằng số và 
phương thức trừu tượng.

* Mối quan hệ giữa lớp và interface được gọi là kế thừa interface, để một lớp kế thừa 
interface ta sử dụng từ khóa implements.

* Interface có vai trò tạo ra những phương thức, hành vi chung cho các lớp tương tự như 
Lớp trừu tượng.

* Bạn không thể tạo ra một đối tượng từ interface thông qua toán tử new.

* Trong UML: Khi một lớp cài đặt một interface thì mối quan hệ này được biểu diễn bởi mũi 
tên nét đứt có tam giác rỗng trỏ từ lớp tới interface; tên interface và phương thức được 
in nghiêng.

Cú pháp khai báo:

modifier interface InterfaceName {
    // constant
    // abstract method
}

public class X implements InterfaceName {
    // Cài đặt các phương thức của InterfaceName
}

Code minh họa:

Ví dụ khai báo cơ bản:

public interface Edible {

public class Dog implements Edible {

7. COMPARABLE INTERFACE

Khái niệm và đặc điểm:

* Comparable Interface định nghĩa một phương thức là compareTo để so sánh object.

* Giả sử bạn cần một phương thức chung để tìm đối tượng lớn hơn trong 2 Sinh viên, 
2 hình tròn... để có thể so sánh 2 đối tượng thì chúng cần phải so sánh được với nhau, 
Java hỗ trợ interface Comparable giúp bạn đạt được điều này.

- Định nghĩa trong thư viện Java:

public interface Comparable<E> {
    public int compareTo(E o);
}

Code minh họa:

- Lớp Student cài đặt Comparable interface:

public class Student implements Comparable {
    private String name;
    private double gpa;
    public Student(String name, double gpa) {
        this.name = name;
        this.gpa = gpa;
    }

    public double getGpa() {
        return this.gpa;
    }

    public String getName() {
        return this.name;
    }

    @Override
    public int compareTo(Student o) {
        if (this.gpa < o.getGpa()) return -1;
        else if (this.gpa > o.getGpa()) return 1;
        else return 0;
    }
}

- Drive Class 1 (Sắp xếp tăng dần theo GPA):

public class Main {
    public static void main(String[] args) {
        ArrayList a = new ArrayList<>();
        a.add(new Student("Teo", 3.1));
        a.add(new Student("Nam", 3.4));
        a.add(new Student("Ty", 2.7));
        a.add(new Student("Phuong", 2.1));
        Collections.sort(a);

        for (Student x : a) {
            System.out.println(x.getName() + " " + x.getGpa());
        }
    }
}

OUTPUT 1:
Phuong 2.1
Ty 2.7
Teo 3.1
Nam 3.4

- Drive Class 2 (Sắp xếp giảm dần với reverseOrder):

8. COMPARATOR INTERFACE

Khái niệm và đặc điểm:

* Bên cạnh Comparable interface, Java còn cung cấp cho bạn interface là Comparator 
để có thể dễ dàng sắp xếp danh sách các object mà người dùng tự định nghĩa ra theo 
nhiều tiêu chí khác nhau.

- Định nghĩa trong thư viện Java:

@FunctionalInterface
public interface Comparator<T> {
    int compare(T o1, T o2);
    boolean equals(Object obj);
}

Code minh họa:

- Lớp Student:

public class Student {

    private double gpa;

        return this.gpa;

    public String getName() {

public class SortStudentByName implements Comparator {
    @Override

* Đọc ghi Files

Xử lý file trong Java được thực hiện thông qua các luồng (Streams). Có hai loại luồng chính:

- Luồng Ký tự (Character Stream): Đọc/ghi dữ liệu dạng văn bản (text file như .txt, .csv). 
Hỗ trợ Unicode (16-bit). Các lớp đại diện: FileReader, FileWriter, BufferedReader, BufferedWriter.

- Luồng Byte (Byte Stream): Đọc/ghi dữ liệu dạng nhị phân (hình ảnh, video, file thực thi). 
Các lớp đại diện: FileInputStream, FileOutputStream.

Tính chất bắt buộc
- Xử lý ngoại lệ (Exception Handling): Mọi thao tác I/O đều có nguy cơ thất bại, do đó Java 
bắt buộc phải bắt IOException (hoặc FileNotFoundException).

- Đóng luồng (Resource Management): Luôn phải gọi hàm .close() sau khi thao tác xong để giải phóng 
bộ nhớ và mở khóa file. 

1. Lớp Scanner và các hàm Kiểm tra/Đọc dữ liệu

- Cơ chế hoạt động của ScannerScanner hoạt động dựa trên các dấu phân cách (delimiters). 
Mặc định, nó sử dụng khoảng trắng (dấu cách, tab, xuống dòng) để cắt luồng dữ liệu thành 
các khối nhỏ gọi là các token.

- Các hàm của Scanner được chia làm 2 nhóm, luôn đi theo cặp:
+ Nhóm hàm hasNext...(): Hàm kiểm tra (trả về boolean). Nhìn xem token tiếp theo có tồn tại và 
có đúng kiểu dữ liệu yêu cầu hay không. Luôn dùng hàm này trước để tránh lỗi NoSuchElementException.
+ Nhóm hàm next...(): Hàm thực thi. Lấy token tiếp theo, chuyển đổi thành kiểu dữ liệu tương ứng 
và đẩy con trỏ tiến lên

Các hàm phổ biến:
+ hasNext() / next(): Đọc chuỗi (String) cho đến khi gặp khoảng trắng.
+ hasNextLine() / nextLine(): Đọc toàn bộ chuỗi trên 1 dòng cho đến khi gặp ký tự xuống dòng \n.
+ hasNextInt() / nextInt(): Đọc và ép kiểu thành số nguyên (int).
+ hasNextDouble() / nextDouble(): Đọc và ép kiểu thành số thực (double).
+ hasNextBoolean() / nextBoolean(): Đọc giá trị logic (true hoặc false).

- Cách dùng Scanner để đọc File
Sử dụng vòng lặp while(scanner.hasNext()) là kỹ thuật chuẩn để duyệt qua toàn bộ dữ liệu 
trong file mà không biết trước file có bao nhiêu dòng/từ.

import java.io*;

public class test {
    public static void main(String[] args) {
        try (Scanner sc = new Scanner(new File("numbers.txt"))) {

            // Đọc liên tục chừng nào file còn chứa số nguyên
            while (sc.hasNextInt()) {
                int number = sc.nextInt();
                System.out.println("Đọc được số: " + number);
            }
        } catch (FileNotFoundException e) {
            System.out.println("Không tìm thấy file!");
        }
    }
}

2. FileWriter là một lớp được sử dụng để ghi dữ liệu dạng ký tự (character-oriented) vào một file. 

- Mục đích: Phù hợp nhất để ghi các file văn bản thông thường (.txt, .csv, .json,...). 
Không dùng FileWriter để ghi dữ liệu nhị phân (hình ảnh, âm thanh, file .exe) – đối với dữ liệu nhị phân, 
phải dùng FileOutputStream.

* Các cách khởi tạo (Constructors)

- Chế độ Ghi đè (Overwrite - Mặc định):
+ Nếu file đã tồn tại, toàn bộ nội dung cũ sẽ bị xóa sạch trước khi ghi nội dung mới. 
+ Nếu file chưa tồn tại, nó sẽ tự động tạo file mới.
    FileWriter fw = new FileWriter("data.txt");

- Chế độ Ghi nối (Append): Thêm tham số true vào constructor. 
+ Nếu file đã có nội dung rồi, nội dung mới sẽ được nối tiếp vào cuối file.
    FileWriter fw = new FileWriter("data.txt", true); 

- Các hàm (Methods) quan trọng:
+ write(String str): Ghi một chuỗi văn bản vào file.
+ write(int c): Ghi một ký tự (thông qua mã ASCII/Unicode của nó).
+ write(char[] cbuf): Ghi một mảng ký tự vào file.
+ write(String str, int off, int len): Ghi một phần của chuỗi (bắt đầu từ vị trí off,
độ dài len).
+ flush(): Đẩy (ép) toàn bộ dữ liệu còn đọng trong bộ đệm (buffer) xuống file ngay lập tức.
+ close(): Bắt buộc! Đóng luồng, giải phóng tài nguyên bộ nhớ và mở khóa file. 
Hàm này sẽ tự động gọi flush() trước khi đóng.

- Cú pháp và Ví dụ thực tế
Vì thao tác với file có thể xảy ra lỗi (VD: ổ cứng đầy, không có quyền ghi), Java bắt buộc bạn 
phải xử lý ngoại lệ IOException.

import java.io.*;
public class FileWriterExample {
    public static void main(String[] args) {
        String data = "Xin chào, đây là nội dung được ghi từ Java!";
        
        try (FileWriter fw = new FileWriter("output.txt")) {
            
            fw.write(data);
            fw.write("\n"); // Ghi ký tự xuống dòng
            fw.write("Đây là dòng thứ 2.");
            
            System.out.println("Ghi file thành công!");
            
        } catch (IOException e) {
            System.out.println("Đã xảy ra lỗi khi ghi file: " + e.getMessage());
        }
    }
}
