* Các lệnh in dữ liệu ra màn hình:

- System.out.print("text");: In chuỗi ra màn hình và giữ con trỏ chuột ở lại 
trên cùng dòng đó.

- System.out.println("text");: In chuỗi ra màn hình và tự động xuống dòng 
(tương đương với việc thêm ký tự \n ở cuối).

- System.out.printf("format", args);: In chuỗi theo định dạng

+ Các ký tự "giữ chỗ" (Format Specifiers) cơ bản:
Ký tự        Kiểu dữ liệu tương ứng                     Ví dụ

%d        Số nguyên (byte, short, int, long)           10, -25
%f        Số thực (float, double)                   3.14159, -0.5
%s          Chuỗi văn bản (String)                     "Java"
%c          Một ký tự (char)                            'A'
%b          Đúng/Sai (boolean)                      true, false
%n (\n)      Ký tự xuống dòng

Ví dụ:
String name = "Hoang";
int age = 25;
// Nối chuỗi bằng println 
System.out.println("Tên tôi là " + name + ", năm nay tôi " + age + " tuổi."); 

// Dùng printf 
System.out.printf("Tên tôi là %s, năm nay tôi %d tuổi.", name, age);

- Định dạng độ chính xác cho số thực (float/double):
Sử dụng lệnh System.out.printf kết hợp với cú pháp %.nf (trong đó n là số lượng 
chữ số thập phân bạn muốn giữ lại). Java sẽ tự động làm tròn số.

Ví dụ:
double pi = 3.14159265;
System.out.printf("Pi với 2 số thập phân: %.2f\n", pi); // In ra: 3.14
System.out.printf("Pi với 4 số thập phân: %.4f\n", pi); // In ra: 3.1416

* Nhập dữ liệu (Input)
Cách đơn giản và phổ biến nhất trong Java là sử dụng class Scanner thuộc thư viện 
java.util.
Ví dụ:
    Scanner sc = new Scanner(System.in);

    System.out.print("Nhập một số nguyên: ");
    int a = sc.nextInt();                   // Đọc số nguyên (int)

    System.out.print("Nhập một số thực: ");
    double b = sc.nextDouble();             // Đọc số thực (double)

    // LƯU Ý QUAN TRỌNG: Xóa bộ nhớ đệm
    sc.nextLine(); 
    System.out.print("Nhập họ và tên: ");
    String name = sc.nextLine();            // Đọc toàn bộ một dòng chữ 
                                            (bao gồm cả dấu cách)
    sc.close();                             // Đóng Scanner khi không dùng nữa để
                                            giải phóng bộ nhớ
  
-> Lỗi "trôi lệnh" thường gặp: Khi bạn dùng các hàm đọc số như nextInt(), nextDouble(), 
chúng chỉ lấy con số mà để lại ký tự Enter \n trong bộ đệm. Nếu gọi ngay nextLine() 
sau đó, nó sẽ đọc trúng ký tự Enter này và kết thúc ngay lập tức. 
Cần gọi một lệnh sc.nextLine() trống ở giữa để "ăn" ký tự Enter thừa đó.

* Arrays.sort và Comparator

- Arrays.sort là một hàm tĩnh (static) trong thư viện java.util.
Arrays dùng để sắp xếp các phần tử trong mảng. Mặc định, hàm này sẽ sắp xếp theo chiều 
tăng dần.

- Sử dụng Comparator (Tùy chỉnh luật sắp xếp):
Comparator là một interface cho phép bạn tự định nghĩa lại cách so sánh hai phần tử 
(ví dụ: muốn sắp xếp giảm dần, hoặc sắp xếp theo độ dài chuỗi).

+ Lưu ý cực kỳ quan trọng: Bạn không thể dùng Comparator cho mảng kiểu nguyên thủy 
(như int[], double[]). Bạn bắt buộc phải dùng mảng kiểu đối tượng 
(như Integer[], Double[], String[]).

public class Main {
    public static void main(String[] args) {
        int[] arrAsc = {5, 2, 8, 1};
        Arrays.sort(arrAsc);            // Kết quả: 1, 2, 5, 8

        Integer[] arrDesc = {5, 2, 8, 1};
        
        // Tự viết luật bằng biểu thức Lambda (Cú pháp mũi tên)
        Arrays.sort(arrDesc, (a, b) -> b - a); 
    }
}

+ Integer: Bắt buộc dùng cho ArrayList<Integer>, Có nhiều hàm hỗ trợ.

* ArrayList: hoạt động như một mảng động có kích thước tự động tăng hoặc giảm khi bạn thêm 
hoặc xóa phần tử. Cho phép chứa giá trị null

- Duyệt ArrayList:
public class Main {
    public static void main(String[] args) {
        // 1. KHAI BÁO
        
        ArrayList<Integer> numbers = new ArrayList<>();

        // 2. NHẬP DỮ LIỆU (INPUT)

        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        for (int i = 0; i < n; i++) {
            System.out.print("Nhập phần tử thứ " + (i + 1) + ": ");
            int value = scanner.nextInt();
            numbers.add(value); 
        }

        // 3. XUẤT DỮ LIỆU (OUTPUT)
        
        // Cách 1: In trực tiếp 
        System.out.println(numbers);

        // Cách 2: Dùng vòng lặp for truyền thống 
        for (int i = 0; i < numbers.size(); i++) { 
            System.out.print(numbers.get(i) + " "); // Dùng hàm get(i) để lấy giá trị tại vị trí i
        }

        // Cách 3: Dùng vòng lặp for-each 
        for (Integer num : numbers) {
            System.out.print(num + " ");
        }
    }
}

+ hàm Thêm phần tử
add(giá_trị): Thêm một phần tử vào cuối danh sách.

list.add(10); 
list.add(20);                   // list hiện tại: [10, 20]
list.add(1, 15);                // Chèn số 15 vào index 1. 
                                Kết quả: [10, 15, 20]

-> add(vị_trí, giá_trị): Chèn một phần tử vào một vị trí (index) cụ thể. 
Các phần tử phía sau sẽ tự động lùi lại một bước.

+ hàm Truy xuất và Tìm kiếm

• get(index): Lấy giá trị của phần tử tại vị trí index (tương đương 
arr[index] của mảng thường).
int x = list.get(0);                    // Trả về 10

• size(): Lấy tổng số lượng phần tử đang có trong danh sách 
(tương đương arr.length).
int count = list.size();                // Trả về 3

• contains(giá_trị): Kiểm tra xem một giá trị có tồn tại trong danh sách hay không. 
Trả về true hoặc false.
boolean check = list.contains(15);      // Trả về true

• indexOf(giá_trị): Tìm và trả về index đầu tiên của giá trị đó. Nếu không tìm thấy, 
trả về -1.
int pos = list.indexOf(20);             // Trả về 2

• isEmpty(): Kiểm tra xem danh sách có rỗng hay không. Trả về true nếu danh sách 
không có phần tử nào (size = 0).

+ hàm Cập nhật và Xóa
• set(index, giá_trị_mới): Ghi đè/thay đổi giá trị của phần tử tại vị trí index 
(tương đương arr[index] = giá_trị_mới).
list.set(0, 99);                        // list trở thành: [99, 15, 20]

• remove(index): Xóa phần tử tại vị trí index. Các phần tử phía sau sẽ tự động dồn lên trước.
list.remove(1);                         // Xóa phần tử ở index 1 (số 15). Kết quả: [99, 20]

• remove(Object): Xóa phần tử theo giá trị (chỉ xóa phần tử đầu tiên tìm thấy). 
Lưu ý: Với ArrayList kiểu số nguyên, bạn phải ép kiểu để tránh nhầm với hàm remove(index).
list.remove(Integer.valueOf(99));       // Xóa số 99. Kết quả: [20]

• clear(): Xóa sạch toàn bộ dữ liệu, biến ArrayList về trạng thái rỗng.

+ hàm Sắp xếp (Sort)
• Khác với mảng tĩnh dùng Arrays.sort(), với ArrayList bạn có 2 cách để sắp xếp:

- Dùng list.sort() (Tăng dần):
list.sort(list); 

- Dùng Lambda Expression: 
Cú pháp:
(danh_sách_tham_số) -> thân_biểu_thức

+ Được phép dùng Lambda: Integer[], String[], Double[], hoặc mảng chứa các 
object do bạn tự định nghĩa.

+ Báo lỗi biên dịch: int[], double[], char[], long[]

Ví dụ:
public class Main {
    public static int tinhTongChuSo(int n) {
        int sum = 0;
        n = Math.abs(n);
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        return sum;
    }

    public static void main(String[] args) {

        List<Integer> arr = new ArrayList<>(Arrays.asList(12, 23, 104, 51, 9));

        arr.sort((o1, o2) -> {
            int tong1 = tinhTongChuSo(o1);
            int tong2 = tinhTongChuSo(o2);
            
            if (tong1 != tong2) {
                return tong1 - tong2; 
            }
            return o2 - o1; 
        });

        System.out.println(arr);
    }
}

* Set: là một interface đại diện cho khái niệm tập hợp toán học

Áp dụng set:
1. Các bài toán liên quan tới việc xóa, thêm, tìm kiếm một phần tử nào đó được thực hiện đi

Tính chất:
+ Không chứa phần tử trùng lặp: Nếu bạn sử dụng hàm add() để thêm một giá trị đã tồn tại 
trong Set, hệ thống sẽ tự động bỏ qua và trả về false.
+ Không truy cập dc chỉ số (Index)

- Cú pháp: Vì là một interface, bạn không thể khởi tạo trực tiếp Set bằng từ khóa new Set(). 
Bạn phải gọi thông qua các lớp triển khai của nó:

    Set<KiểuDữLiệu> tenSet = new TênLớpTriểnKhai<>();

* HashSet:
- Tính chất:
• HashSet chỉ lưu được các phần tử khác nhau.
• HashSet được cài đặt bằng bảng băm, vì thế tốc độ tìm kiếm 
phần tử đạt được là O(1).
• HashSet không có thứ tự, tức là các phần tử trong HashSet 
có thể xuất hiện nhiều thứ tự ngẫu nhiên.
• HashSet chỉ lưu được các phần tử kiểu đối tượng.
• Cho phép chứa duy nhất một phần tử null.

- Khai báo HashSet:
    Set<dataType> set1 = new HashSet<>();
    HashSet<dataType> set2 = new HashSet<>();

- Một số hàm thông dụng trong HashSet:
+ add(giá_trị) Thêm phần tử vào set
+ remove(giá_trị) Xóa phần tử khỏi set
+ size() Trả về số lượng phần tử trong set
+ contains(giá_trị) Kiểm tra sự tồn tại của 1 phần tử trong set
+ clear() Xóa mọi phần tử trong set
+ isEmpty() Trả về true nếu set rỗng, ngược lại trả về false

- Tìm số lượng giá trị khác nhau trong mảng số nguyên:

public static void main(String[] args) {
    Set<Integer> set1 = new HashSet<>();
    int[] a = {1, 1, 2, 1, 3, 1, 4, 4, 2};
    for(int x : a){
        set1.add(x);
    }
    System.out.println(set1.size());
}

- Duyệt set:

public static void main(String[] args) {
    Set<Integer> set1 = new HashSet<>();
    int[] a = {1, 1, 2, 1, 3, 1, 4, 4, 2};
    for(int x : a){
        set1.add(x);
    }
    for(int x : set1){
        System.out.print(x + " ");
    }

- Kiểm tra sự tồn tại của 1 giá trị trong set:

public static void main(String[] args) {
    Set<Integer> set1 = new HashSet<>();
    int[] a = {1, 1, 2, 1, 3, 1, 4, 4, 2};
    for(int x : a){
        set1.add(x);
    }
    if(set1.contains(1)){
        System.out.println("FOUND");
    }
    else{
        System.out.println("NOT FOUND");
    }
}

        System.out.print(x + " ");
    }
}

- Một số hàm thông dụng trong TreeSet:

+ floor(x) Trả về phần tử lớn nhất <= x hoặc trả về null nếu không tồn tại
+ ceiling(x) Trả về phần tử nhỏ nhất >=x hoặc trả về null nếu không tồn tại
+ first() Trả về phần tử đầu tiên trong set
+ last() Trả về phần tử cuối cùng trong set
+ lower(x) Trả về phần tử lớn nhất nhỏ hơn x hoặc trả về null nếu không tồn tại
+ higher(x) Trả về phần tử nhỏ nhất lớn hơn x hoặc trả về null nếu không tồn tại

------------------------------------------------------------------------------------------
* Map, HashMap, LinkedHashMap, TreeMap

- Map là container giúp lưu các phần tử theo cặp key, value (khóa - giá trị).
Mỗi giá trị của key sẽ ánh xạ sang một value tương ứng. So với Set thì Map
thậm chí còn mạnh mẽ và giải quyết được nhiều vấn đề hơn.

- Tính chất:
• Các key trong map là những giá trị riêng biệt, không có 2 key nào 
có giá trị giống nhau, value thì có thể trùng nhau.
• Map có thể tìm kiếm nhanh.
• Map có thể dùng key làm index để truy cập vào value tương ứng.
• Map trong java chỉ lưu các phần tử là object

- Áp dụng map:
+ Các bài toán liên quan tới tần suất của các phần tử.
+ Các bài toán cần tìm kiếm, thêm, xóa phần tử một 
cách nhanh chóng.
+ Dùng map thay cho các bài toán sử dụng mảng
đánh dấu khi dữ liệu không đẹp

Cú pháp:
Map<KiểuKhóa, KiểuGiáTrị> tenMap = new TênLớpTriểnKhai<>();

---------------------------------------------
* HashMap: được cài đặt bằng hash table, Hashmap không có thứ tự nào cả,
các bạn cần chú ý điều đó.

- Tốc độ thêm (put), xóa (remove), và tìm kiếm (get) cực nhanh với độ phức tạp 
thời gian O(1).

Khai báo HashMap:
    Map<keyDataType, valueDataType> map = new HashMap<>();
    HashMap<keyDataType, valueDataType> map = new HashMap<>();

- Các hàm phổ biến của Hashmap:
+ put(key, val) Thêm cặp key, value vào map
+ size() Trả về kích thước của map
+ isEmpty() Kiểm tra map rỗng
+ clear() Xóa toàn bộ các phần tử trong map
+ containsKey(x) Kiểm tra sự tồn tại của phần tử x trong tập key
+ containsValue(x) Kiểm tra sự tồn tại của phần tử x trong tập value
+ get(x) Trả về value tương ứng với key x
+ remove(x) Xóa cặp phần tử có key là x khỏi map
+ replace(x, y) Thay thế cặp phần tử (x, y)

- Duyệt Map:
public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    HashMap<Integer, Integer> map = new HashMap<>();
    map.put(1, 2);
    map.put(1, 4);
    map.put(3, 4);
    map.put(2, 5);
    map.put(2, 3);
    Set<Map.Entry<Integer, Integer>> entrySet = map.entrySet();
    for(Map.Entry<Integer, Integer> entry : entrySet){
        System.out.println(entry.getKey() + " " + entry.getValue());
    }
}

- Kiểm tra sự tồn tại của nhiều phần tử trong tập hợp:

public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    HashMap<Integer, Integer> map = new HashMap<>();
    int[] a = {1, 1, 2, 1, 2, 3, 1, 2};
    for(int x : a)
        map.put(x, 1);
    int q = sc.nextInt();
    while(q-- > 0){
        int x = sc.nextInt();
        if(map.containsKey(x))
        System.out.println("FOUND");
        else
        System.out.println("NOT FOUND");
    }
}

* LinkedHashMap: được cài đặt bằng bảng băm kết hợp với danh sách liên kết,
tương tự như map có điều khác biệt là trong LinkedHashMap có thứ tự, key
sẽ được sắp xếp theo thứ tự bạn thêm nó vào trong map

- Các hàm của LinkedHashMap không có gì khác so với HashMap

* TreeMap được cài đặt bằng cây đỏ đen, key trong TreeMap được sắp xếp
theo thứ tự tăng dần

public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    TreeMap<Integer, Integer> map = new TreeMap<>();
    int[] a = {4, 1, 1, 2, 1, 2, 3, 1, 2};
    for (int x : a) {
        if (map.containsKey(x)) {
            int tanSuat = map.get(x);
            map.put(x, tanSuat + 1);
        } else {
            map.put(x, 1);
        }
    }
    Set<Map.Entry<Integer, Integer>> entrySet = map.entrySet();
    for (Map.Entry<Integer, Integer> entry : entrySet)
        System.out.println(entry.getKey() + " " + entry.getValue());
}

- TreeMap có có thêm các hàm sau:
+ firstKey() Trả về key đầu tiên trong map
+ lastKey() Trả về key cuối cùng trong map
+ firstEntry() Trả về cặp phần tử đầu tiên trong map
+ lastEntry() Trả về cặp phần tử cuối cùng trong map
+ floorKey(x) Trả về key lớn nhất nhỏ hơn hoặc bằng x
+ floorEntry(x) Trả về cặp phần tử có key lớn nhất nhỏ hơn hoặc bằng x
+ ceilingKey(x) Trả về key nhỏ nhất lớn hơn hoặc bằng x
+ ceilingEntry(x) Trả về cặp phần tử có key nhỏ nhất lơn hơn hoặc bằng x
